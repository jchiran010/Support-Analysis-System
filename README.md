# Intelligent Customer Complaint & Support Analysis System

An enterprise-grade Support Analysis System built with Flask, Bootstrap 5, and Chart.js.

## Technology Stack
- **Frontend**: HTML5, CSS3, Bootstrap 5, JavaScript, Chart.js
- **Backend**: Python 3.11, Flask, SQLAlchemy
- **Database**: SQLite3

## Folder Structure
- `Backend/`: Contains the Flask application, routes, and business logic.
- `Frontend/`: Contains Jinja2 templates and static assets (CSS, JS, images).
- `Database/`: Contains the SQLite database file.

## Installation Guide
1. Clone the repository
2. Create a virtual environment: `python -m venv venv`
3. Activate the virtual environment
4. Install dependencies: `pip install -r requirements.txt`
5. Run the application: `python Backend/app.py`

## Features
- Glassmorphism Login
- Interactive Enterprise Dashboard
- Complaint Tracking
- Chart.js Analytics
- Responsive Sidebar
